# Dos mil pasos · la historia del español, un paso por año

Recorrido narrado para caminar con audífonos: 16 paradas de 218 a. C. a 2026, cada paso es un año. Hecho para una clase de bachillerato de dos horas en la Sierra Gorda (UAQ Campus Concá, curso de Etimologías, 2026).

**Abrir:** https://campus-conca.github.io/dos-mil-pasos/ · Tocar «Descargar recorrido», esperar el «Listo», y en iPhone añadirlo a la pantalla de inicio desde Safari. Después funciona sin internet.

Voces generadas con Gemini TTS a partir de un guion propio; sonidos de Freesound (créditos en `CREDITOS-sonidos.md`); imágenes de Wikimedia Commons con crédito al pie de cada una (`imagenes/creditos.json`). Motor: Sendero App (PWA).
